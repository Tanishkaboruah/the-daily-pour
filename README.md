# The Daily Pour : CoffeeCafe

A responsive café homepage demo featuring cinematic coffee-pouring footage, an editorial coffee menu, and a warm, minimalist design.

## Features

* **Responsive design:** Adapts to desktop and mobile screens.
* **Video hero section:** Coffee-pouring footage with layered gradients and soft radial fading.
* **Editorial coffee menu:** Eight sample drinks with descriptions, prices, and images.
* **Café story section:** A dedicated section to introduce the café's concept.
* **Mobile navigation:** JavaScript-powered navigation toggle.
* **Visit section:** A space for café location, opening hours, and contact information.

## Built With

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Unsplash images

## Run Locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Keep `videos/coffee-pour.mp4` inside the `videos` folder so the hero video loads correctly.

## Notes

* This is a **static website demo**, not a production café website.
* Café details, menu items, prices, address, opening hours, and social media information are sample content.
* The enquiry button is a demo interaction and does not process real enquiries.
* Google Fonts and Unsplash images require an internet connection.
* Review the usage rights for all images and video footage before commercial use.
